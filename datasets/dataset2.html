The Dream Dictionary

Clarifying Dream Interpretations by the Great Scholars(3.5MB)

Dataset Overview

This project is a structured collection of dream interpretations from the three most prominent classical scholars: Ibn Sirin Ibn Shahin Al-Nabulsi Unlike modern interpretations that focus on specific dream cases, these scholars mainly provided the symbolic meaning of each element within dreams. Their works form the foundation of Islamic dream interpretation. Each scholar's interpretations were separated into individual CSV files to maintain clarity and cleanliness.

Dataset Statistics

Scholars 3
Dataset Size 3.5MB
Format CSV

Features

  • Section: This column contains the letters (alphabetically) or a major topic, under which related subtopics are organized.
  • Topic: This column contains the specific item whose meaning is to be explained.
  • Meaning: This column explains the topic column.

Inspiration

  • Semantic Aggregation: Grouping similar dream symbols across different scholars.
  • Comparative Analysis: Studying how interpretations evolved between Ibn Sirin and Al-Nabulsi.
  • LLM Training: Fine-tuning models on classical Arabic dream interpretation.
  • Inference-based Search: Building a "Dream Engine" that understands context.

Data Quality && Data Source

The dataset was carefully compiled from tafsiralahlam.net, which aggregates and preserves the works of these scholars. Each scholar's interpretations were separated into individual CSV files to maintain clarity and cleanliness.
